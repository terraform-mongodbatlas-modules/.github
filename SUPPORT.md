# Support

## MongoDB Atlas Support

If you have an active MongoDB Atlas support contract, open a support ticket in the [Atlas UI](https://support.mongodb.com/). That is the fastest path for production issues with Atlas, the Terraform provider, or these modules.

## Community reporting on GitHub

GitHub issues in the [terraform-mongodbatlas-modules](https://github.com/terraform-mongodbatlas-modules) organization are for community reporting and assistance. We do not guarantee an SLA on GitHub responses.

- **Module behavior or HCL:** Open an issue in the specific module repository (see [docs/repos.md](./docs/repos.md)).
- **Terraform provider:** Open an issue in [terraform-provider-mongodbatlas](https://github.com/mongodb/terraform-provider-mongodbatlas).
- **This org hub** (profile, docs, inherited templates): Open an issue in this repository.

Before opening an issue, check [docs/getting-started.md](./docs/getting-started.md), [docs/debug.md](./docs/debug.md), and the [MongoDB Atlas documentation](https://www.mongodb.com/docs/atlas/).

## Terraform core

Issues with Terraform itself belong in the [Terraform repository](https://github.com/hashicorp/terraform/issues).
